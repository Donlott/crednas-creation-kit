# English previews and glossary

Use **English names…** to load your own English message data. The editor displays available readable names beside the stored identifiers or values. Native values remain editable and are not automatically replaced by their English preview.

The local glossary can supply display translations for terms without a loaded message match. Open **Tools → Translation glossary…** to add or remove an override. Previews update when the underlying supported value changes.

Not every raw identifier, enum or Japanese string has a verified translation. An untranslated term remains visible rather than being assigned a guessed meaning. A preview is a reading aid, not a guarantee that two fields refer to the same namespace or runtime behavior.

This feature does not modify the game's localization/message files. Changing a name/help key changes a reference; creating a new item or character does not generate translated text. Glossary preferences stay local to the application configuration and are separate from the exported mod.
