# Supports & Recruitment

Select **Supports & Recruitment**, then choose a section. The module covers compatibility, pair bonuses, support conditions, recruitment, assist rates, linked voices and related item links. Sections share their original source and export together.

## Compatibility and support rules

Compatibility is directed: editing one character-to-character cell does not automatically change the reverse cell. Pair bonuses hold stored combat modifiers and initial-level values. Support conditions can include partner references, route/part/chapter codes, flags, dates and other requirements.

## Recruitment

Recruitment rows expose supported route, support/renown, item/count, flag, type/difficulty and argument values. The editor stores these requirements; it does not evaluate their truth or simulate recruitment events.

Use readable reference previews and navigation to inspect connected characters, skills or items before changing a rule. Unknown enum codes and special default values are retained as raw values. Existing row identities and matrix order stay fixed.

This module does not generate conversations, voice assets, new support pairs or a complete recruitment event for a newly created character.
