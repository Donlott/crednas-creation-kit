# Characters

Choose **Characters** to edit personal values and links. The tabs cover identity-related fields, classes, stats, aptitudes, skills, items, appearance references and advanced values. **Scenario / test records** exposes additional entries outside the usual character list.

## Stats and links

The identified **Personal bases** and **Personal growths** columns are labelled. Aptitudes distinguish their **Starting value** and **Aptitude growth**. Unidentified blocks retain raw labels rather than guessed meanings.

Class, learning, progression, support and profile values are references to other records. Pickers and **Used by** help follow supported links. Changing an appearance reference reuses existing rules; it does not generate a model, portrait or complete character swap.

## Create a character

On the **Character** tab, use **New character…** for an empty record or **Duplicate character…** to copy the selected character's current values. Choose a unique character ID and the creation-time serial. Zero is the default serial; a positive serial must be unused. The serial is fixed after creation, and original slots remain unchanged.

Set up the new record's required links and assignments separately. Creation does not generate independent recruitment rules, story events, supports, localized text or assets. **Remove new character** is available for new records and checks supported incoming references.
