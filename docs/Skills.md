# Skills

Choose **Skills**, select the source you intend to edit and search by identifier or readable name. Primary and auxiliary sources remain distinct, including when they contain the same identifier.

The editor exposes supported numeric values, flags, stat modifiers, vectors, reference lists and grouped conditions. Numeric controls enforce their storage bounds; lists and condition groups retain their nesting rather than being flattened. Raw codes remain raw where their meanings are unknown.

## References

Pickers search known skill references and available translations. **Used by** lists supported current assignments and links from loaded data, with source information. Open a selected use to navigate to its record or learning/progression entry.

A stored use does not show whether a skill is active, inherited, suppressed or legal in a particular battle. Some auxiliary references are evidence only and cannot be edited directly from the usage list.

Skill names/help fields generally refer to existing localization keys. The skill editor changes those references, not the text stored in a localization file. New skill-definition creation is not provided; edit existing supported skill records.
