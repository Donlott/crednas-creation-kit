# Legion

Choose **Legion** to inspect the existing definitions. The **Legion**, **Stored stats**, **Shop & appearance** and **Connected entries** pages separate their supported values and links.

Edit name/help keys, troop/level values, equipment and skill references, sale values, appearance flags and other exposed parameters. Stat labels identify the stored stat; their interpretation as a base, bonus or modifier is not fully established for every field.

Connected entries can show supported deployment assignments, equipment/skill references and appearance links. They do not infer indirect script assignments, equipment legality or the final rendered appearance.

Legion and learning identifiers can use the same textual prefix. They are separate namespaces: use the module's own picker and the correct deployment field rather than assuming a matching string always refers to the same type of entry.

Editing a Legion does not create new gambit animations, sounds or assets. The module edits existing supported definitions and does not simulate combat effects or engine limits.
