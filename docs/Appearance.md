# Appearance rules

Choose **Appearance rules**, then use the source and section selectors to inspect the relevant existing definitions. The module edits supported appearance information, linked assets, variation references, flags and grouped conditions.

An appearance ID can have several matching rules. The editor preserves those records and their conditions; it does not determine their runtime priority or render the resulting model. Unknown codes are shown as raw values.

Reference pickers and live previews help follow supported identifiers. The [AID browser](AIDs.md) provides source grouping, direct-user evidence and connected-rule links. Changes to a rule may affect every character or record that shares it.

Copying values into an existing rule is different from creating assets or inserting an entirely new definition. This module edits supported existing records; it does not import models, textures, portraits or animations.

For the stored condition chain related to Majide's cape, use the investigation shortcuts in [Events](Events.md). They navigate existing data and do not apply a mod automatically.
