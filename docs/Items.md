# Items

Choose **Items** and select the intended source. Edit supported properties such as item type, value/price, flags, weapon or equipment values, conditions, linked skills and appearance references. Source files stay separate when identifiers overlap.

## Create or duplicate

Use **New item…** for a blank definition or **Duplicate item…** to copy current supported values into a new unique item ID. Set the name/help keys and other required references yourself. Creation does not generate descriptions, icons, models or other assets.

Assign the item to inventories, shops, loot or progression where appropriate. Defining it alone does not make it obtainable. **Remove new item** checks supported references before removing a newly created definition; original item identities remain fixed.

**Used by** links supported inventories, skills, shops, progression and other loaded assignments. These checks cover explicit stored references and do not establish every indirect runtime use.

Use [Shop & Loot](Shops-and-loot.md) for shop/lottery/loot rows. Those rows and primary item definitions share their source owner so they do not produce competing exports.
