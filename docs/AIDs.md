# AIDs: appearance identifiers

The **AIDs** module is a browser for appearance identifiers, definitions and observed uses. It helps answer which loaded records reference an appearance flag and where a definition comes from.

Use the **Source** filter to limit results to one file. **Group by file** organizes entries by source; the flat list is useful for identifier searches. The same identifier can have evidence in several sources, and source membership is kept visible rather than silently merged away.

Select an identifier to inspect its definitions, direct users, connected rules and readable previews where available. Follow a supported link to open the corresponding editable record in its own module.

The AID browser does not evaluate appearance conditions or predict the final rendered character. A stored reference is evidence of a link, not proof that the appearance is active in a particular scene. Editing takes place in the linked character/class/item/Legion or [Appearance rules](Appearance.md) view.

There are no model or portrait previews, and identifiers do not include the underlying assets.
