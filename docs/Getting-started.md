# Getting started

Install the package for your operating system using the instructions in the [README](../README.md). Keep every file from the extracted application package together; the Linux installer creates shortcuts pointing to that folder.

1. Choose **Open data…** and select your own supported extracted data. The application does not supply or extract game content.
2. If English names were not found automatically, choose **English names…** and select your own English message folder.
3. Select a module, search for an entry and choose its tab or section.
4. Edit a value and choose **Apply edits**. Valid changes are also applied during supported navigation; invalid values block the change of selection so you can correct them.
5. Save a project and export to a separate mod folder. See [Projects and export](Projects-and-export.md).

## Find entries and references

Search supports native identifiers and available English/glossary previews. Some modules have source, section or category selectors: choose the source you intend to edit. Duplicate identifiers in different sources remain separate records.

Reference pickers help select known linked entries. **Used by** or **Connected entries** can navigate to supported references in loaded data. The lists are not exhaustive runtime dependency checks.

## Personal settings

The application remembers successful data, language, project and export paths. After saving or opening a project, **Open last project** can reopen that project at startup. This is not an autosave of unsaved work.

Settings remain in the existing application configuration location so saved paths and the glossary continue to work. Missing source folders or mismatched project fingerprints are reported before replacing the workspace.
