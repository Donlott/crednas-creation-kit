# GLID automatic progression

Choose **GLID progression**, select a collection and then choose its category row. The level list displays the stored value beside its readable preview. Select a level to edit its cell. **Show empty levels** controls whether blank cells are displayed; the editor does not fill them or simulate progression.

Some observed categories contain class or item names. Their pickers write the stored bare name when that category requires it, rather than inserting an identifier prefix automatically. Other categories remain raw strings or numeric-looking text where their meanings are unverified.

Category codes are stored data, not a complete documented enum. A class/item suggestion does not prove that the selected value is valid for every category or level. Treat blank cells, end-level behavior and unknown codes according to the existing data you are editing.

Supported class and item usage links can navigate to exact progression cells. These links describe explicit stored values; they do not infer every character's resulting progression.
