# Battle deployment

Choose **Battle deployment** and use its source, group and slot selectors to find the placement entry you want to edit. Source-file filtering helps separate different battles or placement sets.

The editor exposes supported character, class, item, skill, AI, group and Legion assignments, plus numeric values and flags present in the selected row. Reference pickers use known loaded definitions; connected-entry links navigate supported targets.

Existing placement group/slot identities and ordering stay fixed. This module does not provide a map preview, terrain painting, free-position drag-and-drop, or arbitrary new placement groups. Numeric coordinates and unknown AI/group codes remain stored values.

A placement reference does not prove that an event activates that slot. Inspect the relevant [Events](Events.md) and character rules when changing recruitment, availability or encounter behavior. The editor does not run the battle to validate those relationships.
