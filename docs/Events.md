# Events

Choose **Events**, select a supported source and then an existing entry. The module edits stored variables/flags, condition groups, ordered timeline arguments, dates, chapter permissions and situation values.

Keep condition grouping and argument order intentional: the editor preserves them, but does not execute the event or infer the meaning of every event-type code. Locked identities, hash keys and existing row ordering stay fixed. Copy/paste applies to compatible editable values, not identities.

## Connections and cape investigation

**Connections** follows supported stored references. The **Majide cape** investigation tab links the observed appearance/condition chain and the related encounter in your own loaded data. It does not apply a cape mod automatically or prove the exact runtime moment when a flag refreshes.

Rules shared by multiple entries can affect more than one character. Test a focused condition change separately before combining it with other modifications.

## Compiled scripts

The **Compiled scripts** tab inspects script metadata from your selected data. Use **Open script editor…** or **Tools → Script editor…** for the supported instruction edits described in [Compiled scripts](Scripts.md).

Event tables and compiled scripts serve different roles. Neither module is a game emulator, story simulator or full dialogue-text editor.
