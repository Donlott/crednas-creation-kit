# Profiles & Affiliations

Select **Profiles & Affiliations** and choose a section. Supported sections cover profiles, affiliations, conversation expressions, conversation restrictions and roster order.

Profiles include personal presentation values, activation/group links, biography/introduction keys, preferences, gifts and related references. Affiliations include name keys, icons, route codes and grouped transition conditions. Expression and roster sections expose their stored presentation codes and ordering values.

Name, biography and introduction values often reference localization keys. English previews can show the corresponding text when your message data is loaded, but changing a key does not rewrite that text.

Grouped conditions remain grouped. Unknown expression/transition codes stay numeric or raw; the editor does not preview a conversation, facial animation or affiliation transition in game.

These sections edit their existing supported records and share one project/export owner. Creating a character does not generate an independent profile, affiliation or new localized biography automatically.
