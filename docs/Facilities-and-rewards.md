# Facilities & Rewards

Select **Facilities & Rewards**, choose the source and section, then select an entry. The module exposes supported facility parameters, linked requirements and rewards.

Facility sections include their stored gameplay values, levels or related conditions where present. Reward definitions can reference items, skills or other supported identifiers. English previews and reference pickers help inspect those links.

Different reward sources remain separate. The editor does not infer an override order or combine similarly named records from different sources into a single definition. Make changes in the source you intend to export.

Unknown category codes and flag meanings remain raw. A valid stored reference does not establish that a facility or reward is reachable, unlocked or legal for a particular game state. Connected-entry links show observed references without evaluating those conditions.

This module edits supported existing entries. It does not create a new facility interface, generate assets or simulate reward delivery.
