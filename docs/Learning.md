# Learning tables

Choose **Learning tables** to inspect and edit supported learn lists. Select a list, then select an entry and edit its requirements, linked content and other stored values. Reference pickers and translations help identify skills and related entries.

## Expand a list

Use **Add entry**, **Duplicate entry** or **Undo last addition** inside a supported list. Additions are appended while original entry order and identities are preserved. A duplicated entry copies its current editable values; it is not a shared edit of the original.

## Create a list

**New list** creates an empty list with a unique identifier. **Duplicate list** copies the selected list and its supported entries. New lists appear in the character learning chooser, but you must assign them to the intended records yourself.

**Remove new list** applies to newly created lists and checks supported incoming references. Deleting existing original lists is not supported. The editor does not determine whether the game accepts every possible list size, requirement combination or new identifier.

Learning lists and automatic [GLID progression](GLID.md) serve different purposes. Inspect the character's relevant links before assuming a learn-list change affects automatic progression.
