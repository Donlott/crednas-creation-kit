CREDNA'S CREATION KIT 1.02 — WINDOWS x64

NO GAME FILES ARE INCLUDED. This program cannot run or emulate games.
It only edits files that you provide.

1. Extract the complete Windows-x64 ZIP to a permanent folder.
2. Run Crednas-Creation-Kit.exe. Python and required libraries are included.
3. Choose Open data... to select your own supported data.
4. Optionally choose English names... for readable previews.
5. Save a project, then export edits to a separate mod folder.

Supports Windows 10/11 on Intel/AMD 64-bit systems. No administrator access
or separate Python installation is needed. Do not run the EXE inside the ZIP.

Read README.md for features and docs/Home.md for the user guide. The guide
covers modules, creation controls, references, compiled-script limits and export.
The application does not generate missing game content or test mods in-game.

Settings/glossary/recent paths remain in the existing application configuration
location. Existing projects remain compatible with their original matching data.
The executable is unsigned. Source/build instructions are in docs/Maintainers.md.
